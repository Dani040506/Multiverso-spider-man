# 🕸️ Spider-Man Multiverses | DIO

Bem-vindo ao Spider-Man Multiverses!
Este repositório apresenta um site interativo inspirado no universo do Homem-Aranha e no conceito de multiversos. O projeto foi desenvolvido como prática dos fundamentos de HTML, CSS e JavaScript, aplicando conceitos modernos de responsividade, manipulação da DOM e estruturação de interfaces.

## 🌐 Sobre o Projeto
O site simula uma experiência visual e temática baseada no multiverso do Spider-Man, explorando versões alternativas do herói em diferentes filmes.
A navegação é totalmente interativa, com efeitos, transições e conteúdo estilizado para entregar uma experiência dinâmica.

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura das páginas
- **CSS3** – Estilização, efeitos e responsividade
- **JavaScript** – Interatividade, animações e manipulação da DOM
-  **Assets customizados** – Imagens, ícones e elementos visuais

##🚀 Funcionalidades do Site

- 🕷️ **Exploração visual do Multiverso do Spider-Man**
Cards, seções temáticas e informações estilizadas sobre versões alternativas.

- 🌀 **Efeitos e transições interativas em JavaScript**
Elementos animados que tornam a experiência dinâmica.

- 🌌 **Design temático inspirado no multiverso**
Com cores, fontes e imagens dentro do estilo Spider-Man.

## 🎯 Objetivo do Projeto
Este site foi criado para praticar:

✔ Estruturação semântica com HTML

✔ Criação de interfaces responsivas

✔ Manipulação do DOM com JavaScript

✔ Animações e transições CSS

✔ Organização de pastas e assets

✔ Construção de uma identidade visual temática
